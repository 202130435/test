# CoinPilot Lab

> 실거래 전에 자동매매 전략을 검증하는 클라우드 기반 암호화폐 모의매매·리스크 관리 플랫폼

CoinPilot Lab은 BTC·ETH·SOL 시장 데이터를 24시간 수집하고 매매 전략을 모의매매로 실행해 성과와 위험을 분석합니다. 포지션 크기, 손절 기준과 일일 손실 한도를 관리하며, 웹과 모바일에서 가상 잔고·포지션·손익·거래 기록과 전략 판단 근거를 확인할 수 있습니다.

현재 버전은 **전략 검증용 MVP**입니다. 선물 모의매매는 실제 Binance USDT-M 공개 데이터를 사용하지만 거래소 주문을 전송하지 않습니다. 현물 주문 경로는 코드로 구현되어 있으나 실제 계정 검증을 마치지 않았습니다.

## 제품이 해결하는 문제

개인 투자자는 충분히 검증하지 않은 전략을 실거래에 적용하거나, 손절과 거래 중단 기준 없이 감정적으로 매매하면서 손실을 키울 수 있습니다. 전략을 장시간 검증하려면 개인 PC를 계속 켜야 하고, 거래 기록·수수료·손실 위험을 직접 정리해야 하는 어려움도 있습니다.

CoinPilot Lab은 다음 과정을 하나의 서비스로 연결합니다.

- VPS 기반 24시간 시장 데이터 수집
- 백테스트와 모의매매를 통한 전략 검증
- 포지션 크기와 손실 한도를 적용한 위험 관리
- 모든 매매 판단과 결과 기록
- 웹 대시보드를 통한 성과 확인

## 주요 사용자

- 선물 매매를 공부하며 실거래 전 검증이 필요한 사용자
- 자신이 만든 전략을 비교하려는 개인 개발자
- 매매 교육을 운영하는 강사와 커뮤니티
- 여러 전략의 성과와 위험을 관리하려는 소규모 트레이딩 팀

## 서비스 이용 흐름

1. 사용자가 종목, 전략과 최대 허용 손실을 설정합니다.
2. 과거 데이터 백테스트로 전략의 기본 성과를 확인합니다.
3. BTC·ETH·SOL 모의매매를 VPS에서 24시간 실행합니다.
4. 웹 대시보드에서 거래 결과와 판단 근거를 검토합니다.
5. 검증 기준을 통과한 전략은 Binance 테스트넷에서 주문 안정성을 확인합니다.
6. 사용자가 위험을 이해하고 직접 결정한 경우에만 거래소 연동 단계로 이동합니다.

현재 구현 범위는 3~4단계입니다. 백테스트 보고서와 선물 테스트넷 주문은 개발 로드맵에 포함되어 있습니다.

## 제품의 차별점

- 백테스트, 장기 모의매매, 테스트넷 검증을 순서대로 수행하는 구조
- 수익률과 함께 수수료, 최대 손실과 거래 중단 조건을 관리
- 결과뿐 아니라 진입·관망·차단 판단의 근거까지 기록
- 거래당 최대 손실액에서 손절 거리와 주문 수량을 역산
- 개인 PC 없이 VPS에서 실행하고 웹·모바일에서 상태 확인
- 지역 제한과 접근 제한이 발생하면 자동 우회하거나 주문을 반복하지 않고 중단

## 개발 기록 — 2026-11-09

오늘 프로젝트의 기본 구조부터 선물 매매 계획 엔진까지 구현했습니다.

### 현물 봇

- Binance 공개 시세를 사용하는 BTC/USDT 현물 SMA 5/20 교차 전략을 구현했습니다.
- 기본 실행은 실제 주문이 없는 로컬 모의매매이며, `--live`와 확인 문구를 모두 입력해야만 현물 실거래 경로가 열립니다.
- SQLite에 잔고·포지션·마지막 처리 봉·주문 상태를 저장합니다.
- 같은 상태 DB의 중복 실행을 잠금 파일로 차단하고, 응답이 불확실한 주문은 자동 재주문하지 않고 정지시킵니다.
- Windows와 Linux/macOS에서 같은 잠금 방식을 사용할 수 있도록 `portalocker`를 적용하고 PowerShell 실행 방법을 추가했습니다.

### 네트워크 대응

- 외부 요청에 기본 3.5초 타임아웃을 적용했습니다.
- 공개 시장 데이터만 `api.binance.com`, `api1`, `api2`, `api3` 순서로 제한적으로 폴백합니다.
- 451 지역 제한과 403/418/429 접근·요청 제한에는 폴백하지 않고 정지합니다.
- 잔고 조회와 실제 주문은 자동 재시도하거나 다른 호스트로 전환하지 않습니다.

### 선물 전략과 강의 내용 반영

- 완성된 일봉과 4시간봉의 SMA 50/200으로 큰 시장 사이클을 판정합니다.
- 완성된 15분봉의 작은 사이클 변곡으로 롱·축소 숏·관망·청산 후보를 만듭니다.
- 다이버전스, 불/베어 트랩, 상대 거래량, OI·펀딩 맥락과 시간 손절을 독립적인 근거 함수로 구현했습니다.
- 강의의 7개 진입 전 체크리스트를 점수제가 아닌 필수 검토 절차로 구현했습니다.
- 손절가를 먼저 정한 뒤 수수료·슬리피지·펀딩 버퍼를 포함해 1R 이내 수량을 계산합니다.
- 모의 테스트 시작값으로 거래당 0.5%, 일일 3R, 최대 2배 레버리지, 연속 손실 3회, 하루 6회 거래 제한을 적용했습니다. 이 값들은 강의에서 제시한 고정값이 아니므로 백테스트 후 조정해야 합니다.
- 수익 중인 포지션에 확인 신호가 있을 때만 추가 진입을 허용하고, 손절 확대와 물타기를 차단했습니다.
- 25%씩 네 번 나누는 익절 계획을 선택 기능으로 구현했습니다.

### 24시간 데이터 수집

- Docker Compose로 BTC·ETH·SOL 모의매매를 각각 독립 실행할 수 있습니다.
- 모든 15분봉 판단과 모든 청산 거래를 SQLite 테이블에 제한 없이 누적합니다.
- 실행 중에도 안전한 DB 백업과 JSON·CSV 내보내기를 지원합니다.
- systemd로 서버 부팅 시 자동 시작하고 하루 한 번 DB를 백업할 수 있습니다.
- Docker 로그는 크기와 파일 수를 제한해 서버 디스크가 로그로 가득 차는 것을 막습니다.
- 읽기 전용 웹 대시보드에서 BTC·ETH·SOL 잔고, 포지션, 누적 손익, 최근 거래와 전략 판단을 확인할 수 있습니다.

### 현재 검증 상태와 다음 작업

### Windows PowerShell

Python 3.12를 설치하고 프로젝트 파일을 PC에 내려받은 뒤, `bot.py`가 있는 폴더에서 PowerShell을 여세요. GitHub 저장소에서 Code → Download ZIP을 선택해 내려받거나 Git으로 복제할 수 있습니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe bot.py --once
```

계속 모의매매하려면:

```powershell
.\.venv\Scripts\python.exe bot.py
```

가상환경 활성화가 필요 없어 PowerShell 실행 정책을 변경하지 않아도 됩니다. `py`를 찾지 못하면 Python 설치 및 Python Launcher 설치 여부를 확인하세요. `--once`가 출력 없이 정상 종료할 경우 시세 조회는 완료했지만 매매 신호가 없었던 것입니다. `--live`를 지정하지 않으면 실제 주문을 보내지 않으며 API 키도 필요하지 않습니다. 종료는 Ctrl+C입니다. Windows와 Linux/macOS에서 파일 잠금은 `portalocker`로 처리합니다.

현재 클라우드에서는 `.venv/bin/python` 대신 `/workspace/coin-bot-venv/bin/python`을 사용할 수 있습니다.

기본 전략: BTC/USDT, 1분 봉의 5/20 단순이동평균 교차. 완성된 봉에서 상승 교차 시 시장가 매수, 하락 교차 시 봇이 보유한 수량만 매도합니다. 기본 가상 자본은 100 USDT, 매수 금액은 10 USDT, 모의 수수료는 0.1%입니다. `--symbol`, `--timeframe`, `--fast`, `--slow`, `--capital`, `--quote-amount`, `--fee`로 조정합니다. 매매 신호가 없으면 주문하지 않습니다.

상태는 SQLite에 저장하며 같은 데이터베이스를 쓰는 동시 실행은 차단합니다. 모드·전략을 변경할 때는 별도 `--state` 경로를 사용하세요. 종료는 Ctrl+C입니다. 종료해도 보유 코인은 자동으로 매도하지 않습니다.

## 선물 모의매매 실행

`futures_paper.py`는 Binance USDT-M의 공개 일봉·4시간봉·15분봉과 OI를 읽습니다. API 키 없이 로컬에서 가상 체결만 기록하며 실제 주문 함수는 호출하지 않습니다.

Windows PowerShell에서 한 번만 실행해 상태를 확인하려면:

```powershell
.\.venv\Scripts\python.exe futures_paper.py --once
```

계속 실행하려면:

```powershell
.\.venv\Scripts\python.exe futures_paper.py
```

기본 설정은 BTC/USDT 무기한 선물, 가상 자본 1,000 USDT, 레버리지 상한 2배, 거래당 위험 0.5%, 일일 손실 3R, 롱 전용입니다. 숏 모의매매도 허용하려면 기존 롱 전용 상태와 분리된 DB를 사용하세요.

```powershell
.\.venv\Scripts\python.exe futures_paper.py --allow-short --state futures-paper-long-short.sqlite3
```

프로그램은 매분 확인하지만 새 15분봉이 완성됐을 때만 전략을 처리합니다. `wait`, `blocked`, `entry`, `hold`, `exit` 이벤트를 JSON 한 줄로 출력하고 `futures-paper.sqlite3`에 저장합니다. 상태 JSON에는 빠른 조회용 최근 100개 청산 기록을 유지하고, 전체 기록은 별도 테이블에 보존합니다. 설정을 변경할 때는 다른 `--state` 파일을 지정해야 합니다.

DB의 `events` 테이블에는 모든 15분봉 판단, `trades` 테이블에는 모든 청산 거래가 제한 없이 누적됩니다. 상태 확인과 실행 중 백업·CSV 내보내기는 다음처럼 사용할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe paper_data.py status --state futures-paper.sqlite3
.\.venv\Scripts\python.exe paper_data.py backup --state futures-paper.sqlite3 --output backup.sqlite3
.\.venv\Scripts\python.exe paper_data.py export --state futures-paper.sqlite3 --output-dir exports\btc-v1
```

엄격 체크리스트가 기본이며 상대 거래량, 최근 거래 집중 가격대, 가격 구조와 공개 OI 검토를 통과해야 진입합니다. 현재 펀딩비는 위험 버퍼에만 반영하고 실제 펀딩 지급·수취는 가상 잔고에 반영하지 않습니다. 과거 수익률이나 실거래 수익을 보장하지 않습니다.

## 웹 대시보드

웹 화면은 모의매매 SQLite DB를 읽기 전용으로 열며 주문을 실행하거나 전략 설정을 변경하지 않습니다. 로컬에서 확인하려면 DB가 있는 디렉터리를 지정하고 서버를 실행합니다.

```sh
PAPER_DATA_DIR=. .venv/bin/uvicorn web_app:app --host 127.0.0.1 --port 8080
```

브라우저에서 `http://127.0.0.1:8080`을 열면 됩니다. 화면은 30초마다 갱신되며 JSON 상태는 `/api/dashboard`, 프로세스 상태는 `/health`에서 확인할 수 있습니다.

Docker Compose에서는 `dashboard` 서비스가 함께 시작되지만 호스트의 `127.0.0.1:8080`에만 연결됩니다. 비밀번호와 HTTPS 없이 인터넷에 직접 공개하지 마세요. 외부 기기에서는 SSH 터널 또는 Tailscale Serve를 사용합니다.

이 클라우드에서는 Binance Futures가 HTTP 451을 반환했지만, 사용자의 Windows 네트워크에서 접속 가능한 경우 위 명령으로 실행할 수 있습니다. 로컬에서도 451이 발생하면 우회하지 말고 계정·지역 이용 가능 여부를 Binance에 확인하세요.

## 실거래

실거래 주문 경로는 구현했지만 실제 계정에서 검증하지 않았습니다. 손절, 최대 손실 제한, 자동 주문 복구, 슬리피지 제한은 아직 없습니다. 모의매매와 주문 테스트를 충분히 검증한 후 사용하세요. 전략 수익성은 검증되지 않았습니다.

여기의 실거래 경로는 **현물 봇만** 가리킵니다. 선물 모의매매는 `futures_system.py`가 만든 `TradePlan`을 로컬 가상 체결에만 사용하며 실제 주문 전송 경로가 없습니다.

전용 계정/API 키 사용을 권장합니다. 출금 권한 없이 현물 거래 권한만 부여하세요. `BINANCE_API_KEY`와 `BINANCE_API_SECRET`을 안전한 실행 환경에서 공급해야 합니다. 키를 코드·Git·채팅에 넣지 마세요. Binance HMAC 서명에는 프로세스가 사용할 수 있는 실제 secret이 필요하며 HTTPS 프록시 치환용 placeholder는 사용할 수 없습니다.

직접 실행하려면 다음 두 옵션을 함께 지정해야 합니다:

```sh
.venv/bin/python bot.py --live --confirm-live BINANCE_SPOT_REAL_ORDERS --state live.sqlite3 --quote-amount 10 --capital 100
```

`--capital`은 봇 내부 예산이며 계좌 전체 잔고가 아닙니다. 봇은 단일 포지션만 유지합니다. 시장가 체결 금액은 가격 변동으로 설정한 매수 금액을 초과할 수 있습니다. 최소 주문 수량/금액을 충족하지 못하면 정지합니다. 수수료와 정밀도로 발생한 잔여 수량은 수동 확인이 필요할 수 있습니다.

주문 전 intent를 영구 저장합니다. 응답 유실, 부분 체결 또는 불명확한 응답이면 실행 및 재시작을 중단하며 자동 재주문하지 않습니다. 바이낸스에서 `spotbot-<봉 timestamp>-<buy/sell>` 주문 ID를 조회하여 체결·잔고를 확인하고 DB를 백업한 뒤 상태를 수동 조정해야 합니다. 미해결 상태를 지우거나 새 DB로 무작정 재시작하면 중복 주문이 생길 수 있습니다. 여러 DB로 같은 계정을 동시에 운영하지 마세요.

## 네트워크

`api.binance.com` HTTPS 접근이 필요합니다. 클라우드 프록시와 CA 설정을 그대로 사용하고 TLS 검증을 유지합니다. 지역 제한이나 네트워크 오류를 우회하지 않습니다. 오류가 나면 봇은 정지합니다.

## 타임아웃과 공개 API 장애 대응

[참고 글](https://velog.io/@whird625/바이낸스-에러-해결)의 타임아웃과 다중 호스트 접근을 현물 봇에 맞게 적용했습니다.

요청 타임아웃은 기본 3,500ms이며 `--timeout-ms`로 변경합니다. 이는 요청별 제한이며 전체 실행 시간을 3.5초로 제한하는 것은 아닙니다. 공개 시장정보·봉 조회가 타임아웃 또는 일시적 서버/연결 오류로 실패하면 `api.binance.com`, `api1.binance.com`, `api2.binance.com`, `api3.binance.com` 순서로 최대 한 번씩 시도합니다. 이 호스트들도 클라우드 네트워크 허용 목록에 있어야 합니다.

451 지역 제한 및 403/418/429 접근 제한·요청 제한에는 폴백하지 않고 정지합니다. 실거래 잔고 조회와 주문 전송은 기본 호스트를 유지하고 자동 재시도하지 않습니다. `data-api.binance.vision`은 주문을 처리하는 API가 아니므로 주문 대상으로 추가하지 않았습니다. 리전 변경은 이 프로젝트의 코드 설정으로 할 수 없으며, 현재 클라우드에서 반환된 451의 정확한 지역 원인은 확인되지 않았습니다.

# 선물 다중 시간대 전략

`futures_strategy.py`는 주문을 전송하지 않는 순수 신호·리스크 모듈이다. 모든 입력은 아직 움직이는 현재 봉을 제외한 **완성된 봉**이어야 한다. 기본 진입 봉은 15분 봉을 권장한다.

## 1. 큰 시장 사이클

일봉과 4시간봉을 각각 다음과 같이 분류한다. 이동평균은 단순이동평균(SMA)이다.

```text
상승 정배열 = 종가 > SMA50 > SMA200
             AND SMA50 상승 중
             AND SMA200 상승 중

하락 역배열 = 종가 < SMA50 < SMA200
             AND SMA50 하락 중
             AND SMA200 하락 중

나머지 = 중립
```

두 시간대가 모두 상승 정배열일 때만 최종 시장 상태를 `BULL`로 판정한다. 두 시간대가 모두 하락 역배열일 때만 `BEAR`로 판정한다. 일봉과 4시간봉이 서로 다르거나 이동평균이 얽혀 있으면 `NEUTRAL`이다.

이렇게 하면 일봉만 상승이고 4시간봉이 하락 전환한 구간에서 성급하게 롱에 진입하지 않는다. 최소 201개의 완성된 일봉과 201개의 완성된 4시간봉이 필요하다.

## 2. 마트로시카 진입 구조

큰 사이클 안의 작은 사이클은 기본적으로 15분 봉 SMA5와 SMA20 교차로 판단한다.

```text
작은 상승 변곡 = 이전 SMA5 <= 이전 SMA20
                 AND 현재 SMA5 > 현재 SMA20
                 AND 종가 > 현재 SMA5

작은 하락 변곡 = 이전 SMA5 >= 이전 SMA20
                 AND 현재 SMA5 < 현재 SMA20
                 AND 종가 < 현재 SMA5
```

포지션이 없을 때 판단표는 다음과 같다.

| 큰 시장 상태 | 작은 사이클 | 기본 행동 | 근거 |
| --- | --- | --- | --- |
| `BULL` | 상승 변곡 | 롱 진입 | 일봉·4시간 상승 흐름 안에서 단기 상승이 재개됨 |
| `BULL` | 그 외 | 관망 | 이미 오른 구간을 추격하지 않고 다음 변곡을 기다림 |
| `NEUTRAL` | 모든 상태 | 관망 | 큰 시간대가 합의되지 않음 |
| `BEAR` | 모든 상태 | 관망 | 기본 정책은 하락장에서 롱을 금지하고 현금 상태 유지 |
| `BEAR` | 하락 변곡 | 축소 숏 | `allow_short=True`를 명시한 경우에만 허용 |

숏을 허용해도 기본 위험 배수는 `0.25`다. 예를 들어 일반 롱에서 계좌의 0.5%를 위험에 노출한다면 숏은 0.125%만 노출한다. 이는 요구한 “비중 최소화 또는 관망”을 설정으로 선택할 수 있게 한 것이다.

고정된 한 번의 교차만 노리는 구조가 아니다. 상승 정배열이 유지되는 동안 작은 하락 변곡에서 포지션을 닫고, 다음 작은 상승 변곡에서 다시 진입한다. 큰 인형 안에서 작은 인형을 반복하는 방식으로 추세 내부의 여러 파동을 분리해 거래한다. 거래 횟수가 늘면 수수료와 슬리피지도 늘기 때문에 누적 수익을 보장하지는 않는다.

## 3. 손절과 무포지션 헤지

롱 진입 시 초기 손절가는 다음 세 기준을 조합한다.

```text
기술적 손절 = 최근 10개 15분 봉의 최저가보다 0.1% 아래
변동성 손절 = 진입가 - 2 × ATR(14)
최대 허용 거리 = 진입가보다 3% 아래

최종 손절 = 기술적·변동성 기준 중 더 넓은 값,
            단 진입가에서 최대 3%를 넘기지 않음
```

숏은 위 조건을 대칭으로 계산한다. 실제 주문 모듈에서는 이 가격을 거래소 서버에 조건부 청산 주문으로 등록해야 한다. 프로그램이 꺼져 있어도 손절이 남아 있어야 하기 때문이다.

롱 보유 중에는 다음 조건을 우선순위대로 평가한다.

1. 해당 봉의 저가가 보호 손절가에 닿으면 즉시 롱 청산으로 판정한다.
2. 일봉·4시간 상승 정배열이 깨지면 롱을 청산하고 무포지션으로 전환한다.
3. 15분 SMA5가 SMA20 아래로 하향 교차하면 단기 하락 사이클로 보고 롱을 청산한다.
4. 위 조건이 없으면 롱을 유지하면서 손절가를 SMA20 또는 `종가 - 2×ATR` 방향으로만 올린다. 손절가는 다시 낮추지 않는다.

숏은 반대 조건으로 동작한다. 이 전략에서 “헤지”의 기본 의미는 반대 포지션을 동시에 잡는 것이 아니라 위험 자산 노출을 0으로 만드는 것이다. 양방향 포지션은 수수료·증거금·복구 상태를 복잡하게 만들기 때문에 포함하지 않았다.

## 4. 포지션 크기와 일일 중단

기본 위험 한도는 거래당 계좌 평가금의 0.5%, 레버리지 상한은 2배다.

```text
허용 손실액 = 기준 평가금 × 0.005 × 위험 배수
단위당 손실 = |진입가 - 손절가| + 예상 왕복 수수료
              + 예상 왕복 슬리피지 + 펀딩 버퍼
위험 기준 수량 = 허용 손실액 / 단위당 손실
레버리지 기준 최대 수량 = 계좌 평가금 × 2 / 진입가

최종 수량 = min(위험 기준 수량, 레버리지 기준 최대 수량)
```

`futures_risk.py`는 이 계산에 예상 비용을 포함하고, 일일 3R·연속 손실 3회·하루 6회 거래에서 세션을 중단하는 개발 시작값을 제공한다. 이 수치는 강의에서 제시한 값이 아니며 백테스트로 조정해야 한다. 자세한 구분은 [COURSE_SPEC.md](COURSE_SPEC.md)를 따른다.

## 5. 코드 사용 예

```python
from futures_risk import DailyRiskState
from futures_system import plan_entry
from trade_checklist import ChecklistAssessment

assessment = ChecklistAssessment(
    signal_reviewed=True,
    location_reviewed=True,
    location_valid=True,
    timeframe_reviewed=True,
    timeframe_aligned=True,
    volume_reviewed=True,
    volume_confirmed=True,
    repeated_signal_risk_reviewed=True,
    structure_reviewed=True,
    structure_confirmed=True,
    oi_reviewed=True,
)

result = plan_entry(
    daily=closed_daily_candles,
    four_hour=closed_4h_candles,
    trigger_candles=closed_15m_candles,
    assessment=assessment,
    equity=account_equity,
    leverage=2,
    daily_state=DailyRiskState("2026-11-09", account_equity),
)

if result.ready:
    print(result.trade_plan)
```

`result.decision.reasons`에는 전략 근거, `result.blocked_reasons`에는 체크리스트 또는 위험 차단 사유가 들어 있다. 이를 거래 일지와 모바일 알림에 사용할 수 있다.

## 6. 아직 주문에 연결되지 않은 부분

현재 `bot.py`는 기존 현물 1분봉 SMA5/20 봇이다. 선물 쪽은 신호(`futures_strategy.py`), 시장 근거(`market_evidence.py`), 체크리스트(`trade_checklist.py`), 위험 및 주문 계획(`futures_risk.py`, `futures_system.py`)과 공개 데이터 기반 로컬 모의매매 실행기(`futures_paper.py`)까지 구현되어 있다. 실제 선물 주문 실행에는 다음 작업이 추가로 필요하다.

- USDT-M 선물 데이터와 계정 상태 조회
- 격리 마진·단방향 모드·레버리지 검증
- 실제 체결가를 기준으로 수량과 손절가 재계산
- 거래소 서버에 `reduceOnly` 손절·익절 주문 등록
- 부분 체결, 재시작, 수동 주문 및 미확정 주문 동기화
- 수수료·슬리피지·펀딩비를 포함한 백테스트
- 테스트넷 및 최소 금액 단계별 검증

이 작업이 끝나기 전에는 선물 실거래용으로 사용할 수 없다.

# 강의 기반 선물 시스템 명세

이 문서는 강의 4~6강에서 확인된 원칙을 자동매매 코드로 옮길 때의 기준이다. 강의에서 말한 내용과 구현자가 백테스트를 위해 정한 시작값을 구분한다. 현재 `futures_paper.py`는 주문 계획을 로컬 가상 체결로 실행하지만 거래소에 선물 주문을 보내지 않는다.

## 판단 흐름

진입은 다음 순서를 모두 통과해야 한다.

1. `futures_strategy.py`가 완성된 일봉·4시간봉으로 큰 추세를 정하고, 완성된 15분봉에서 작은 변곡을 찾는다.
2. `trade_checklist.py`가 강의의 7개 항목을 전부 검토했는지 확인한다.
3. 매물대 위치, 시간축, 거래량, 가격 구조의 필수 관문을 통과한다.
4. 시장·종목 위험 등 별도 거부 사유가 없어야 한다.
5. `futures_risk.py`가 손절가와 비용을 기준으로 수량을 역산한다.
6. 일일 손실, 연속 손실, 거래 횟수 중단 조건을 통과한 경우에만 `TradePlan`이 생성된다.

지표 개수를 더해 점수를 만드는 방식은 사용하지 않는다. OI, 펀딩비, 청산맵, RSI, 다이버전스는 방향을 단독으로 결정하지 않고 맥락 또는 경고로만 사용한다.

## 진입 전 7개 체크리스트

| 순서 | 확인 질문 | 코드 역할 |
| ---: | --- | --- |
| 1 | 진짜 다이버전스인가, 트랩인가? | 신호 분류를 검토했는지 확인 |
| 2 | 그 자리에 매물대가 있는가? | 승인한 지지·저항 구역인지 필수 확인 |
| 3 | 신호 시간축과 보유 계획이 일치하는가? | 시간축 불일치 시 진입 차단 |
| 4 | 거래량이 실제로 확인되는가? | 거래량 확인이 없으면 진입 차단 |
| 5 | 다이버전스가 반복될 가능성을 열어두었는가? | 중첩 신호 위험 검토 |
| 6 | 가격 구조가 실제로 회복 또는 붕괴했는가? | 완성 봉의 구조 확인 전 진입 차단 |
| 7 | 바닥/고점에서 OI가 쌓이고 있는가? | 방향 신호가 아닌 위험 맥락 검토 |

`market_evidence.py`는 일반 상승·하락 다이버전스, 완성 봉의 불/베어 트랩, 상대 거래량, 가격 상승+OI 증가+음수 펀딩의 숏 스퀴즈 맥락, 시간 손절을 순수 함수로 제공한다. 강의에서 정의하지 않은 피벗 선택, 봉 간격, 거래량 배수, OI 변화율과 시간 손절 봉 수는 함수 입력으로 남겨 두었다.

## 손실을 먼저 정하는 수량 계산

강의의 순서는 손절가 결정 → 손절 거리 확인 → 허용 손실액 결정 → 수량 역산이다. 코드에서는 예상 왕복 수수료, 왕복 슬리피지와 펀딩 버퍼도 1R 안에 포함한다.

```text
1R = 기준 평가금 × 거래당 위험률 × 위험 배수
단위당 예상 손실 = |진입가 - 손절가|
                   + 진입가 × 왕복 수수료율
                   + 진입가 × 왕복 슬리피지율
                   + 진입가 × 펀딩 버퍼
위험 기준 수량 = 1R / 단위당 예상 손실
레버리지 상한 수량 = 현재 평가금 × 레버리지 / 진입가
최종 수량 = min(위험 기준 수량, 레버리지 상한 수량)
```

수익으로 현재 평가금이 늘어도 같은 세션의 1R을 자동으로 키우지 않는다. 평가금이 줄면 더 작은 현재 평가금을 사용해 위험을 즉시 줄인다.

## 초기 개발 설정

아래 값은 발표자의 규칙이 아니라 모의 테스트용 보수적 시작값이다.

| 항목 | 시작값 | 출처 |
| --- | ---: | --- |
| 거래당 위험 | 시작 평가금의 0.5% | 개발 설정 |
| 일일 손실 한도 | 3R | 개발 설정 |
| 최대 레버리지 | 2배 | 프로젝트의 보수적 상한 |
| 연속 손실 중단 | 3회 | 개발 설정 |
| 일일 최대 거래 | 6회 | 개발 설정 |
| 예상 수수료 | 편도 0.05% | 개발 설정, 거래소 등급에 맞게 수정 필요 |
| 예상 슬리피지 | 편도 0.05% | 개발 설정, 체결 데이터로 보정 필요 |

발표자의 1회 2,000달러와 하루 10,000달러는 개인 예시이므로 기본값으로 사용하지 않는다. 강의의 2~3배, 근거가 있을 때 5배라는 언급도 프로젝트 상한을 높이는 근거로 사용하지 않는다.

## 포지션 구축과 청산

- 탐색 진입 비율은 강의에서 고정되지 않았다. `100/1,000`은 설명용 예시다.
- 추가 진입은 기존 포지션이 수익 중이고 새 확인 신호가 있으며 손절을 넓히지 않고 전체 가격 위험과 비용이 기존 1R 이내일 때만 허용한다.
- 손실 포지션에 수량을 더하는 물타기는 허용하지 않는다.
- 25%씩 네 번 익절은 발표자의 개인 예시이므로 선택 설정으로만 제공한다. 익절 가격은 사전에 별도로 정해야 한다.
- 재진입은 새로운 근거와 새로운 손절을 가진 새 거래로 취급해야 한다.
- 시간 손절의 봉 수와 최소 기대 반응은 강의에 수치가 없으므로 백테스트 설정값이다.

## 일일 중단과 재개

실현 손익에서 수수료를 빼고 펀딩 손익을 더한 순손익으로 일일 손실을 계산한다. 일일 손실, 연속 손실 또는 거래 횟수 한도에 도달하면 세션을 중단한다. 같은 `session_id`로는 위험 상태를 초기화할 수 없으며, 새 세션 ID와 평가금을 명시해야 한다. 자동 당일 재개는 구현하지 않았다.

## 주문 연결 전 남은 검증

- BTC 중심의 수수료·슬리피지·펀딩 포함 워크포워드 백테스트
- 피벗, 매물대, 거래량, OI와 시간 손절 임계값 결정
- 선물 테스트넷에서 격리 마진, 단방향 모드, 레버리지와 최소 주문 검증

"""Binance spot SMA bot. Defaults to local paper execution."""
import argparse
import json
import os
import sqlite3
import time
import portalocker
import math

import ccxt
from connectivity import SpotExchange, RegionRestricted, public_read


def signal(candles, fast, slow):
    if len(candles) < slow + 1:
        return None
    closes = [float(c[4]) for c in candles]
    def above(end):
        values = closes[:end] if end else closes
        return sum(values[-fast:]) / fast > sum(values[-slow:]) / slow
    previous, current = above(-1), above(0)
    return 'buy' if current and not previous else 'sell' if previous and not current else None


def order_amount(exchange, symbol, budget, price):
    market = exchange.market(symbol)
    amount = float(exchange.amount_to_precision(symbol, budget / price))
    limits = market.get('limits', {})
    for kind, value in [('amount', amount), ('cost', amount * price)]:
        bounds = limits.get(kind) or {}
        if bounds.get('min') is not None and value < bounds['min']:
            raise ValueError(f'Order below minimum {kind}')
        if bounds.get('max') is not None and value > bounds['max']:
            raise ValueError(f'Order above maximum {kind}')
    if amount <= 0 or amount * price > budget * 1.000001:
        raise ValueError('Invalid order amount')
    return amount


class State:
    def __init__(self, path, identity, cash):
        self.lock = open(str(path) + '.lock', 'a')
        try:
            portalocker.lock(self.lock, portalocker.LOCK_EX | portalocker.LOCK_NB)
        except portalocker.exceptions.LockException:
            self.lock.close()
            raise RuntimeError('Another bot uses this state database')
        self.db = sqlite3.connect(path)
        self.db.execute('CREATE TABLE IF NOT EXISTS state (id INTEGER PRIMARY KEY, data TEXT)')
        row = self.db.execute('SELECT data FROM state WHERE id=1').fetchone()
        self.data = json.loads(row[0]) if row else dict(identity=identity, cash=cash, position=0, candle=0, pending=None)
        if self.data['identity'] != identity:
            raise ValueError('State belongs to another mode/symbol/strategy; use another database')
        if self.data['pending']:
            raise RuntimeError('Unresolved order: reconcile it with Binance before resuming; do not blindly retry')
        self.save()
    def save(self):
        self.db.execute('INSERT OR REPLACE INTO state VALUES (1,?)', (json.dumps(self.data),))
        self.db.commit()


def step(exchange, state, args):
    candles = public_read(exchange, exchange.fetch_ohlcv, args.symbol, args.timeframe, limit=args.slow + 2)
    # Ignore the final, still-forming candle.
    closed = candles[:-1]
    if len(closed) < args.slow + 1:
        raise ValueError('Insufficient closed candles')
    stamp, price = closed[-1][0], float(closed[-1][4])
    if stamp <= state.data['candle']:
        return
    side = signal(closed, args.fast, args.slow)
    d = state.data
    if (side == 'buy' and d['position'] == 0) or (side == 'sell' and d['position'] > 0):
        if side == 'buy':
            budget = min(args.quote_amount, d['cash'] / (1 + args.fee))
            if args.live:
                balance = exchange.fetch_balance()
                budget = min(budget, float(balance['free'].get(exchange.market(args.symbol)['quote'], 0)) / (1 + args.fee))
            amount = order_amount(exchange, args.symbol, budget, price)
        else:
            amount = float(exchange.amount_to_precision(args.symbol, d['position']))
            order_amount(exchange, args.symbol, amount * price, price)
            if args.live:
                free = float(exchange.fetch_balance()['free'].get(exchange.market(args.symbol)['base'], 0))
                if free < amount:
                    raise ValueError('Insufficient base balance; reconcile position')
        client_id = f'spotbot-{stamp}-{side}'
        if args.live:
            # Durable intent precedes submission. Any uncertain result halts restart.
            d['pending'] = client_id
            state.save()
            order = exchange.create_order(args.symbol, 'market', side, amount, None, {'newClientOrderId': client_id})
            if order.get('status') != 'closed' or not order.get('filled') or order.get('cost') is None:
                raise RuntimeError('Order not conclusively filled; reconcile pending order')
            filled, cost = float(order['filled']), float(order['cost'])
            fees = order.get('fees') or ([order['fee']] if order.get('fee') else [])
            base_fee = sum(float(f['cost']) for f in fees if f.get('currency') == exchange.market(args.symbol)['base'])
            quote_fee = sum(float(f['cost']) for f in fees if f.get('currency') == exchange.market(args.symbol)['quote'])
        else:
            filled, cost, base_fee, quote_fee = amount, amount * price, 0, amount * price * args.fee
        if side == 'buy':
            d['cash'] -= cost + quote_fee
            d['position'] += filled - base_fee
        else:
            d['cash'] += cost - quote_fee
            d['position'] -= filled + base_fee
            if abs(d['position']) < 1e-12:
                d['position'] = 0
        d['pending'] = None
        print(json.dumps(dict(side=side, amount=filled, cost=cost, mode='live' if args.live else 'paper')), flush=True)
    d['candle'] = stamp
    state.save()

"""Bounded failover for public reads only; private orders are never retried."""
import sys

import ccxt

PUBLIC_HOSTS = ('api.binance.com', 'api1.binance.com', 'api2.binance.com', 'api3.binance.com')


class RegionRestricted(RuntimeError):
    pass


class SpotExchange(ccxt.binance):
    def handle_http_status_code(self, code, reason, url, method, body):
        if code == 451:
            raise RegionRestricted(
                'Binance HTTP 451: this execution location is restricted. '
                'No alternate host or order retry was attempted. '
                'Verify eligibility and contact Binance support.'
            )
        if code in (403, 418, 429):
            raise ccxt.PermissionDenied(f'Binance HTTP {code}: access denied or rate limited; stopping')
        return super().handle_http_status_code(code, reason, url, method, body)


def public_read(exchange, operation, *args, **kwargs):
    original = exchange.urls['api']['public']
    try:
        for index, host in enumerate(PUBLIC_HOSTS):
            exchange.urls['api']['public'] = f'https://{host}/api/v3'
            try:
                return operation(*args, **kwargs)
            except (ccxt.RateLimitExceeded, ccxt.DDoSProtection):
                raise
            except ccxt.NetworkError:
                if index == len(PUBLIC_HOSTS) - 1:
                    raise RuntimeError('All Binance public hosts failed; no order submitted by this read') from None
                print(f'Public read unavailable at {host}; trying next host', file=sys.stderr)
    finally:
        exchange.urls['api']['public'] = original

            raise RegionRestricted(

class PaperState:
    def __init__(self, path, identity, capital):
        self.lock = open(str(path) + ".lock", "a")
        try:
            portalocker.lock(self.lock, portalocker.LOCK_EX | portalocker.LOCK_NB)
        except portalocker.exceptions.LockException:
            self.lock.close()
            raise RuntimeError("Another futures paper bot uses this state database")
        self.db = sqlite3.connect(path)
        self.db.execute("PRAGMA busy_timeout=5000")
        self.db.execute(
            "CREATE TABLE IF NOT EXISTS state (id INTEGER PRIMARY KEY, data TEXT)"
        )
        self.db.execute(
            """
            CREATE TABLE IF NOT EXISTS events (
                candle INTEGER PRIMARY KEY,
                event TEXT NOT NULL,
                payload TEXT NOT NULL,
                created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
            )
            """
        )
        self.db.execute(
            """
            CREATE TABLE IF NOT EXISTS trades (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                opened_at INTEGER NOT NULL UNIQUE,
                closed_at INTEGER NOT NULL,
                side TEXT NOT NULL,
                entry_price REAL NOT NULL,
                exit_price REAL NOT NULL,
                quantity REAL NOT NULL,
                gross_pnl REAL NOT NULL,
                fees REAL NOT NULL,
                net_pnl REAL NOT NULL,
                reason TEXT NOT NULL
            )
            """
        )
        row = self.db.execute("SELECT data FROM state WHERE id=1").fetchone()
        self.data = (
            json.loads(row[0])
            if row
            else {
                "identity": identity,
                "balance": capital,
                "position": None,
                "candle": 0,
                "daily": None,
                "trades": [],
            }
        )
        if self.data["identity"] != identity:
            raise ValueError(
                "State belongs to another futures paper configuration; use another database"
            )
        self.save()

    def save(self):
        payload = json.dumps(self.data, separators=(",", ":"))
        self.db.execute("INSERT OR REPLACE INTO state VALUES (1,?)", (payload,))
        self.db.commit()

    def record_event(self, candle, event, payload):
        self.db.execute(
            "INSERT OR IGNORE INTO events (candle,event,payload) VALUES (?,?,?)",
            (
                candle,
                event,
                json.dumps(payload, ensure_ascii=False, separators=(",", ":")),
            ),
        )

    def record_trade(self, trade):
        self.db.execute(
            """
            INSERT OR IGNORE INTO trades (
                opened_at,closed_at,side,entry_price,exit_price,quantity,
                gross_pnl,fees,net_pnl,reason
            ) VALUES (?,?,?,?,?,?,?,?,?,?)
            """,
            (
                trade["opened_at"],
                trade["closed_at"],
                trade["side"],
                trade["entry_price"],
                trade["exit_price"],
                trade["quantity"],
                trade["gross_pnl"],
                trade["fees"],
                trade["net_pnl"],
                trade["reason"],
            ),
        )


def closed_candles(exchange, symbol, timeframe, limit):
    candles = exchange.fetch_ohlcv(symbol, timeframe, limit=limit)
    if len(candles) < 2:
        raise ValueError(f"Insufficient {timeframe} candles")
    return candles[:-1]


def candle_session_id(timestamp_ms):
    instant = datetime.fromtimestamp(timestamp_ms / 1000, tz=timezone.utc)
    return instant.astimezone(ZoneInfo("Asia/Seoul")).date().isoformat()


def current_equity(data, mark_price):
    position = data["position"]
    if not position:
        return float(data["balance"])
    direction = 1 if position["side"] == "long" else -1
    unrealized = (
        mark_price - float(position["entry_price"])
    ) * float(position["quantity"]) * direction
    return float(data["balance"]) + unrealized


def paper_fill(price, side, opening, slippage_rate):
    buying = (opening and side == "long") or (not opening and side == "short")
    return price * (1 + slippage_rate if buying else 1 - slippage_rate)


def automatic_assessment(
    trigger_candles,
    side,
    oi_reviewed,
    volume_multiplier,
):
    lookback = 20
    history = trigger_candles[-(lookback + 1) : -1]
    last = trigger_candles[-1]
    total_volume = sum(float(candle[5]) for candle in history)
    if total_volume > 0:
        volume_zone = sum(
            ((float(candle[2]) + float(candle[3]) + float(candle[4])) / 3)
            * float(candle[5])
            for candle in history
        ) / total_volume
        tolerance = max(
            volume_zone * 0.005,
            atr(trigger_candles, 14),
        )
        location_valid = abs(float(last[4]) - volume_zone) <= tolerance
    else:
        location_valid = False
    try:
        volume_confirmed = relative_volume_confirmed(
            [float(candle[5]) for candle in trigger_candles],
            lookback=lookback,
            multiplier=volume_multiplier,
        )
    except ValueError:
        volume_confirmed = False
    return ChecklistAssessment(
        signal_reviewed=True,
        location_reviewed=True,
        location_valid=location_valid,
        timeframe_reviewed=True,
        timeframe_aligned=True,
        volume_reviewed=True,
        volume_confirmed=volume_confirmed,
        repeated_signal_risk_reviewed=True,
        structure_reviewed=True,
        structure_confirmed=side in {"long", "short"},
        oi_reviewed=oi_reviewed,
    )


def open_interest_reviewed(exchange, symbol):
    if not exchange.has.get("fetchOpenInterest"):
        return False, None
    value = exchange.fetch_open_interest(symbol)
    amount = value.get("openInterestAmount")
    if amount is None:
        amount = value.get("openInterestValue")
    try:
        number = float(amount)
    except (TypeError, ValueError):
        return False, None
    return math.isfinite(number) and number >= 0, number


def _position(data):
    stored = data["position"]
    if not stored:
        return Position()
    return Position(
        side=stored["side"],
        entry_price=float(stored["entry_price"]),
        stop_price=float(stored["stop_price"]),
    )


def _daily_state(data, session_id, equity):
    stored = data["daily"]
    if stored is None:
        return DailyRiskState(session_id, equity)
    daily = DailyRiskState(**stored)
    if daily.session_id != session_id:
        return daily.start_new_session(session_id, equity)
    return daily


def _emit(**values):
    print(json.dumps(values, ensure_ascii=False, separators=(",", ":")), flush=True)


def _record_event(state, candle, event, **values):
    payload = {"event": event, **values}
    state.record_event(candle, event, payload)
    _emit(**payload)


def paper_step(
    exchange,
    state,
    args,
    strategy_config,
    risk_config,
    assessment_builder=automatic_assessment,
):
    daily = closed_candles(
        exchange, args.symbol, "1d", strategy_config.regime_slow + 2
    )
    four_hour = closed_candles(
        exchange, args.symbol, "4h", strategy_config.regime_slow + 2
    )
    trigger_limit = max(
        strategy_config.trigger_slow + 2,
        strategy_config.atr_period + 2,
        strategy_config.swing_lookback + 2,
        62,
    )
    trigger = closed_candles(exchange, args.symbol, "15m", trigger_limit)
    stamp = int(trigger[-1][0])
    mark_price = float(trigger[-1][4])
    if stamp <= state.data["candle"]:
        _emit(event="already_processed", candle=stamp)
        return

    equity = current_equity(state.data, mark_price)
    session_id = candle_session_id(stamp)
    daily_state = _daily_state(state.data, session_id, equity)
    position = _position(state.data)
    decision = decide(daily, four_hour, trigger, position, strategy_config)

    if decision.action in {Action.EXIT_LONG, Action.EXIT_SHORT}:
        stored = state.data["position"]
        side = stored["side"]
        if decision.reasons == ("protective stop crossed",):
            candle_open = float(trigger[-1][1])
            stop = float(stored["stop_price"])
            base_exit = min(candle_open, stop) if side == "long" else max(candle_open, stop)
        else:
            base_exit = mark_price
        exit_price = paper_fill(base_exit, side, False, args.slippage)
        quantity = float(stored["quantity"])
        direction = 1 if side == "long" else -1
        gross_pnl = (exit_price - float(stored["entry_price"])) * quantity * direction
        exit_fee = exit_price * quantity * args.fee
        total_fees = float(stored["entry_fee"]) + exit_fee
        state.data["balance"] += gross_pnl - exit_fee
        daily_state = daily_state.record_closed_trade(
            gross_pnl=gross_pnl,
            fees=total_fees,
            config=risk_config,
        )
        trade = {
            "side": side,
            "entry_price": stored["entry_price"],
            "exit_price": exit_price,
            "quantity": quantity,
            "gross_pnl": gross_pnl,
            "fees": total_fees,
            "net_pnl": gross_pnl - total_fees,
            "opened_at": stored["opened_at"],
            "closed_at": stamp,
            "reason": decision.reasons[0],
        }
        state.data["trades"] = (state.data["trades"] + [trade])[-100:]
        state.data["position"] = None
        state.record_trade(trade)
        _record_event(state, stamp, "exit", balance=state.data["balance"], **trade)
    elif decision.action in {Action.HOLD_LONG, Action.HOLD_SHORT}:
        state.data["position"]["stop_price"] = decision.stop_price
        _record_event(
            state,
            stamp,
            "hold",
            side=position.side,
            mark_price=mark_price,
            stop_price=decision.stop_price,
            equity=equity,
            reasons=decision.reasons,
        )
    elif decision.action in {Action.ENTER_LONG, Action.ENTER_SHORT}:
        side = "long" if decision.action == Action.ENTER_LONG else "short"
        oi_reviewed, open_interest = open_interest_reviewed(exchange, args.symbol)
        assessment = assessment_builder(
            trigger,
            side,
            oi_reviewed,
            args.volume_multiplier,
        )
        result = plan_entry(
            daily=daily,
            four_hour=four_hour,
            trigger_candles=trigger,
            assessment=assessment,
            equity=equity,
            leverage=args.leverage,
            daily_state=daily_state,
            strategy_config=strategy_config,
            risk_config=risk_config,
        )
        if result.ready:
            plan = result.trade_plan
            entry_price = paper_fill(mark_price, side, True, args.slippage)
            entry_fee = entry_price * plan.quantity * args.fee
            state.data["balance"] -= entry_fee
            state.data["position"] = {
                "side": side,
                "entry_price": entry_price,
                "stop_price": plan.stop_price,
                "quantity": plan.quantity,
                "entry_fee": entry_fee,
                "opened_at": stamp,
            }
            _record_event(
                state,
                stamp,
                "entry",
                side=side,
                entry_price=entry_price,
                stop_price=plan.stop_price,
                quantity=plan.quantity,
                risk_budget=plan.risk_budget,
                open_interest=open_interest,
            )
        else:
            _record_event(
                state,
                stamp,
                "blocked",
                action=decision.action.value,
                mark_price=mark_price,
                open_interest=open_interest,
                reasons=result.blocked_reasons,
            )
    else:
        _record_event(
            state,
            stamp,
            "wait",
            regime=decision.regime.value,
            mark_price=mark_price,
            equity=equity,
            reasons=decision.reasons,
        )

    state.data["daily"] = asdict(daily_state)
    state.data["candle"] = stamp
    state.save()

    funding_rate_buffer: float = 0.0
    allow_reduced_risk_near_daily_limit: bool = False

    def __post_init__(self):
        numeric = (
            self.risk_fraction,
            self.daily_loss_limit_r,
            self.max_leverage,
            self.fee_rate_per_side,
            self.slippage_rate_per_side,
            self.funding_rate_buffer,
        )
        if not all(isfinite(value) and value >= 0 for value in numeric):
            raise ValueError("risk configuration values must be finite and non-negative")
        if not 0 < self.risk_fraction < 1:
            raise ValueError("risk fraction must be between 0 and 1")
        if self.daily_loss_limit_r < 1 or self.max_leverage < 1:
            raise ValueError("daily loss R and maximum leverage must be at least 1")
        if self.max_consecutive_losses < 1 or self.max_daily_trades < 1:
            raise ValueError("loss and trade count limits must be positive")


@dataclass(frozen=True)
class DailyRiskState:
    session_id: str
    session_start_equity: float
    gross_realized_pnl: float = 0.0
    fees_paid: float = 0.0
    funding_pnl: float = 0.0
    trade_count: int = 0
    consecutive_losses: int = 0
    halted: bool = False
    halt_reason: str | None = None

    def __post_init__(self):
        if not self.session_id:
            raise ValueError("session ID is required")
        values = (self.session_start_equity, self.gross_realized_pnl, self.fees_paid, self.funding_pnl)
        if not all(isfinite(value) for value in values) or self.session_start_equity <= 0:
            raise ValueError("invalid daily risk state values")
        if self.fees_paid < 0 or self.trade_count < 0 or self.consecutive_losses < 0:
            raise ValueError("fees and counters cannot be negative")

    @property
    def net_realized_pnl(self) -> float:
        return self.gross_realized_pnl - self.fees_paid + self.funding_pnl

    @property
    def consumed_loss(self) -> float:
        return max(0.0, -self.net_realized_pnl)

    def standard_risk(self, config: RiskConfig) -> float:
        return self.session_start_equity * config.risk_fraction

    def daily_loss_limit(self, config: RiskConfig) -> float:
        return self.standard_risk(config) * config.daily_loss_limit_r

    def remaining_daily_risk(self, config: RiskConfig) -> float:
        return max(0.0, self.daily_loss_limit(config) - self.consumed_loss)

    def entry_block_reason(self, config: RiskConfig) -> str | None:
        if self.halted:
            return self.halt_reason or "session is halted"
        if self.trade_count >= config.max_daily_trades:
            return "maximum daily trade count reached"
        if self.consecutive_losses >= config.max_consecutive_losses:
            return "maximum consecutive losses reached"
        standard = self.standard_risk(config)
        remaining = self.remaining_daily_risk(config)
        if remaining <= 0:
            return "daily loss limit reached"
        if remaining < standard and not config.allow_reduced_risk_near_daily_limit:
            return "remaining daily risk is below one standard trade risk"
        return None

    def record_closed_trade(
        self,
        gross_pnl: float,
        fees: float = 0.0,
        funding_pnl: float = 0.0,
        config: RiskConfig = RiskConfig(),
    ) -> "DailyRiskState":
        if not all(isfinite(value) for value in (gross_pnl, fees, funding_pnl)) or fees < 0:
            raise ValueError("invalid closed trade values")
        trade_net = gross_pnl - fees + funding_pnl
        updated = replace(
            self,
            gross_realized_pnl=self.gross_realized_pnl + gross_pnl,
            fees_paid=self.fees_paid + fees,
            funding_pnl=self.funding_pnl + funding_pnl,
            trade_count=self.trade_count + 1,
            consecutive_losses=self.consecutive_losses + 1 if trade_net < 0 else 0,
        )
        reason = updated.entry_block_reason(config)
        if reason:
            return replace(updated, halted=True, halt_reason=reason)
        return updated

    def start_new_session(self, session_id: str, equity: float) -> "DailyRiskState":
        """Explicit reset; callers must not auto-resume the halted session."""
        if session_id == self.session_id:
            raise ValueError("a new session ID is required to reset daily risk")
        return DailyRiskState(session_id=session_id, session_start_equity=equity)


@dataclass(frozen=True)
class TradePlan:
    side: str
    entry_price: float
    stop_price: float
    quantity: float
    notional: float
    leverage: float
    required_margin: float
    price_loss: float
    estimated_fees: float
    estimated_slippage: float
    funding_buffer: float
    total_planned_loss: float
    risk_budget: float


def build_trade_plan(
    side: str,
    entry_price: float,
    stop_price: float,
    equity: float,
    leverage: float,
    daily_state: DailyRiskState,
    config: RiskConfig = RiskConfig(),
    risk_multiplier: float = 1.0,
) -> TradePlan:
    if side not in {"long", "short"}:
        raise ValueError("side must be long or short")
    values = (entry_price, stop_price, equity, leverage, risk_multiplier)
    if not all(isfinite(value) and value > 0 for value in values):
        raise ValueError("trade plan inputs must be finite and positive")
    if leverage > config.max_leverage:
        raise ValueError("requested leverage exceeds configured maximum")
    if not 0 < risk_multiplier <= 1:
        raise ValueError("risk multiplier must be between 0 and 1")
    if side == "long" and stop_price >= entry_price:
        raise ValueError("long stop must be below entry")
    if side == "short" and stop_price <= entry_price:
        raise ValueError("short stop must be above entry")
    reason = daily_state.entry_block_reason(config)
    if reason:
        raise RuntimeError(reason)

    # A profitable session must not silently increase the configured 1R. A
    # drawdown, however, immediately reduces it with the current equity.
    risk_equity = min(equity, daily_state.session_start_equity)
    standard_budget = risk_equity * config.risk_fraction * risk_multiplier
    remaining = daily_state.remaining_daily_risk(config)
    if remaining < standard_budget and not config.allow_reduced_risk_near_daily_limit:
        raise RuntimeError("remaining daily risk is below requested trade risk")
    risk_budget = min(standard_budget, remaining)
    price_distance = abs(entry_price - stop_price)
    fee_distance = entry_price * config.fee_rate_per_side * 2
    slippage_distance = entry_price * config.slippage_rate_per_side * 2
    funding_distance = entry_price * config.funding_rate_buffer
    loss_per_unit = price_distance + fee_distance + slippage_distance + funding_distance
    quantity_by_risk = risk_budget / loss_per_unit
    quantity_by_leverage = equity * leverage / entry_price
    quantity = min(quantity_by_risk, quantity_by_leverage)
    if quantity <= 0:
        raise ValueError("calculated quantity must be positive")
    notional = quantity * entry_price
    price_loss = quantity * price_distance
    estimated_fees = quantity * fee_distance
    estimated_slippage = quantity * slippage_distance
    funding_buffer = quantity * funding_distance
    total = price_loss + estimated_fees + estimated_slippage + funding_buffer
    if total > risk_budget and not isclose(total, risk_budget, rel_tol=1e-12):
        raise AssertionError("planned loss exceeds risk budget")
    return TradePlan(
        side=side,
        entry_price=entry_price,
        stop_price=stop_price,
        quantity=quantity,
        notional=notional,
        leverage=leverage,
        required_margin=notional / leverage,
        price_loss=price_loss,
        estimated_fees=estimated_fees,
        estimated_slippage=estimated_slippage,
        funding_buffer=funding_buffer,
        total_planned_loss=total,
        risk_budget=risk_budget,
    )


def validate_liquidation_buffer(
    side: str,
    entry_price: float,
    stop_price: float,
    liquidation_price: float,
    minimum_buffer_fraction: float = 0.005,
) -> bool:
    values = (entry_price, stop_price, liquidation_price, minimum_buffer_fraction)
    if not all(isfinite(value) and value >= 0 for value in values) or entry_price <= 0:
        raise ValueError("invalid liquidation buffer inputs")
    if side == "long":
        return liquidation_price < stop_price and (stop_price - liquidation_price) / entry_price >= minimum_buffer_fraction
    if side == "short":
        return liquidation_price > stop_price and (liquidation_price - stop_price) / entry_price >= minimum_buffer_fraction
    raise ValueError("side must be long or short")


@dataclass(frozen=True)
class PositionLeg:
    entry_price: float
    quantity: float

    def __post_init__(self):
        if not all(isfinite(value) and value > 0 for value in (self.entry_price, self.quantity)):
            raise ValueError("position leg values must be finite and positive")


def combined_price_risk(legs: Sequence[PositionLeg], stop_price: float) -> float:
    if not legs or not isfinite(stop_price) or stop_price <= 0:
        raise ValueError("legs and positive stop price are required")
    return sum(leg.quantity * abs(leg.entry_price - stop_price) for leg in legs)


def allow_scale_in(
    side: str,
    existing_legs: Sequence[PositionLeg],
    proposed_leg: PositionLeg,
    current_price: float,
    old_stop: float,
    new_stop: float,
    risk_budget: float,
    confirmation_present: bool,
    cost_buffer: float = 0.0,
) -> bool:
    if side not in {"long", "short"} or not existing_legs:
        raise ValueError("valid side and existing position are required")
    values = (current_price, old_stop, new_stop, risk_budget)
    if not all(isfinite(value) and value > 0 for value in values):
        raise ValueError("scale-in values must be finite and positive")
    if not isfinite(cost_buffer) or cost_buffer < 0:
        raise ValueError("cost buffer must be finite and non-negative")
    average = sum(leg.entry_price * leg.quantity for leg in existing_legs) / sum(
        leg.quantity for leg in existing_legs
    )
    profitable = current_price > average if side == "long" else current_price < average
    adding_to_winner = (
        proposed_leg.entry_price >= average
        if side == "long"
        else proposed_leg.entry_price <= average
    )
    stop_not_widened = new_stop >= old_stop if side == "long" else new_stop <= old_stop
    total_risk = combined_price_risk((*existing_legs, proposed_leg), new_stop) + cost_buffer
    return (
        confirmation_present
        and profitable
        and adding_to_winner
        and stop_not_widened
        and total_risk <= risk_budget
    )


@dataclass(frozen=True)
class TakeProfitOrder:
    price: float
    fraction: float
    quantity: float


def build_take_profit_plan(
    side: str,
    entry_price: float,
    total_quantity: float,
    levels: Sequence[float],
    fractions: Sequence[float],
) -> tuple[TakeProfitOrder, ...]:
    if side not in {"long", "short"}:
        raise ValueError("side must be long or short")
    if (
        not isfinite(entry_price)
        or entry_price <= 0
        or not isfinite(total_quantity)
        or total_quantity <= 0
        or not levels
        or len(levels) != len(fractions)
    ):
        raise ValueError("quantity and matching take-profit levels are required")
    if not all(isfinite(value) and value > 0 for value in (*levels, *fractions)):
        raise ValueError("take-profit values must be finite and positive")
    if not isclose(sum(fractions), 1.0, abs_tol=1e-12):
        raise ValueError("take-profit fractions must total 1")
    if side == "long" and any(left >= right for left, right in zip(levels, levels[1:])):
        raise ValueError("long take-profit levels must increase")
    if side == "short" and any(left <= right for left, right in zip(levels, levels[1:])):
        raise ValueError("short take-profit levels must decrease")
    if side == "long" and any(price <= entry_price for price in levels):
        raise ValueError("long take-profit levels must be above entry")
    if side == "short" and any(price >= entry_price for price in levels):
        raise ValueError("short take-profit levels must be below entry")
    return tuple(
        TakeProfitOrder(price=price, fraction=fraction, quantity=total_quantity * fraction)
        for price, fraction in zip(levels, fractions)
    )

"""Pure multi-timeframe signal and risk logic for USDT-M futures.

Only closed candles may be passed to this module. It never sends orders.
OHLCV rows use the CCXT layout: timestamp, open, high, low, close, volume.
"""

from dataclasses import dataclass
from enum import Enum
from math import isfinite
from typing import Sequence


Candle = Sequence[float]


class Regime(str, Enum):
    BULL = "bull"
    BEAR = "bear"
    NEUTRAL = "neutral"


class Action(str, Enum):
    ENTER_LONG = "enter_long"
    ENTER_SHORT = "enter_short"
    EXIT_LONG = "exit_long"
    EXIT_SHORT = "exit_short"
    HOLD_LONG = "hold_long"
    HOLD_SHORT = "hold_short"
    WAIT = "wait"


@dataclass(frozen=True)
class StrategyConfig:
    regime_fast: int = 50
    regime_slow: int = 200
    trigger_fast: int = 5
    trigger_slow: int = 20
    atr_period: int = 14
    atr_multiple: float = 2.0
    swing_lookback: int = 10
    stop_buffer: float = 0.001
    max_stop_distance: float = 0.03
    risk_fraction: float = 0.005
    max_leverage: float = 2.0
    allow_short: bool = False
    bear_risk_multiplier: float = 0.25

    def __post_init__(self):
        if not 1 < self.regime_fast < self.regime_slow:
            raise ValueError("regime windows must satisfy 1 < fast < slow")
        if not 1 < self.trigger_fast < self.trigger_slow:
            raise ValueError("trigger windows must satisfy 1 < fast < slow")
        if self.atr_period < 2 or self.swing_lookback < 2:
            raise ValueError("ATR period and swing lookback must be at least 2")
        values = (
            self.atr_multiple,
            self.stop_buffer,
            self.max_stop_distance,
            self.risk_fraction,
            self.max_leverage,
            self.bear_risk_multiplier,
        )
        if not all(isfinite(value) and value >= 0 for value in values):
            raise ValueError("risk settings must be finite and non-negative")
        if self.atr_multiple <= 0 or not 0 <= self.stop_buffer < 1:
            raise ValueError("invalid ATR multiple or stop buffer")
        if not 0 < self.max_stop_distance < 1 or not 0 < self.risk_fraction < 1:
            raise ValueError("stop distance and risk fraction must be between 0 and 1")
        if self.max_leverage < 1 or not 0 <= self.bear_risk_multiplier <= 1:
            raise ValueError("invalid leverage or bearish risk multiplier")
        if self.allow_short and self.bear_risk_multiplier == 0:
            raise ValueError("enabled shorts require a positive bearish risk multiplier")


@dataclass(frozen=True)
class Position:
    side: str = "flat"
    entry_price: float | None = None
    stop_price: float | None = None

    def __post_init__(self):
        if self.side not in {"flat", "long", "short"}:
            raise ValueError("position side must be flat, long, or short")
        if self.side == "flat":
            if self.entry_price is not None or self.stop_price is not None:
                raise ValueError("flat position cannot have entry or stop prices")
            return
        if self.entry_price is None or self.stop_price is None:
            raise ValueError("open position requires entry and stop prices")
        if not all(
            isfinite(value) and value > 0
            for value in (self.entry_price, self.stop_price)
        ):
            raise ValueError("position prices must be finite and positive")
        if self.stop_price == self.entry_price:
            raise ValueError("stop must differ from entry")

@dataclass(frozen=True)
class Decision:
    action: Action
    regime: Regime
    reasons: tuple[str, ...]
    stop_price: float | None = None
    risk_multiplier: float = 0.0


def _closes(candles: Sequence[Candle]) -> list[float]:
    values = [float(candle[4]) for candle in candles]
    if not values or not all(isfinite(value) and value > 0 for value in values):
        raise ValueError("candles require finite positive closes")
    return values


def sma(values: Sequence[float], period: int, end: int | None = None) -> float:
    subset = values if end is None else values[:end]
    if len(subset) < period:
        raise ValueError(f"at least {period} values are required")
    return sum(subset[-period:]) / period


def classify_timeframe(candles: Sequence[Candle], config: StrategyConfig) -> Regime:
    closes = _closes(candles)
    required = config.regime_slow + 1
    if len(closes) < required:
        raise ValueError(f"at least {required} closed regime candles are required")
    fast = sma(closes, config.regime_fast)
    slow = sma(closes, config.regime_slow)
    previous_fast = sma(closes, config.regime_fast, -1)
    previous_slow = sma(closes, config.regime_slow, -1)
    price = closes[-1]
    if price > fast > slow and fast > previous_fast and slow > previous_slow:
        return Regime.BULL
    if price < fast < slow and fast < previous_fast and slow < previous_slow:
        return Regime.BEAR
    return Regime.NEUTRAL


def market_regime(
    daily: Sequence[Candle], four_hour: Sequence[Candle], config: StrategyConfig
) -> Regime:
    daily_regime = classify_timeframe(daily, config)
    four_hour_regime = classify_timeframe(four_hour, config)
    if daily_regime == four_hour_regime == Regime.BULL:
        return Regime.BULL
    if daily_regime == four_hour_regime == Regime.BEAR:
        return Regime.BEAR
    return Regime.NEUTRAL


def _trigger(candles: Sequence[Candle], config: StrategyConfig) -> str | None:
    closes = _closes(candles)
    required = config.trigger_slow + 1
    if len(closes) < required:
        raise ValueError(f"at least {required} closed trigger candles are required")
    fast_now = sma(closes, config.trigger_fast)
    slow_now = sma(closes, config.trigger_slow)
    fast_previous = sma(closes, config.trigger_fast, -1)
    slow_previous = sma(closes, config.trigger_slow, -1)
    if fast_previous <= slow_previous and fast_now > slow_now and closes[-1] > fast_now:
        return "up"
    if fast_previous >= slow_previous and fast_now < slow_now and closes[-1] < fast_now:
        return "down"
    return None


def atr(candles: Sequence[Candle], period: int) -> float:
    if len(candles) < period + 1:
        raise ValueError(f"at least {period + 1} candles are required for ATR")
    ranges = []
    for previous, current in zip(candles[-period - 1 : -1], candles[-period:]):
        high, low, previous_close = float(current[2]), float(current[3]), float(previous[4])
        if not all(isfinite(value) and value > 0 for value in (high, low, previous_close)):
            raise ValueError("candles require finite positive OHLC values")
        if low > high:
            raise ValueError("candle low cannot exceed high")
        ranges.append(max(high - low, abs(high - previous_close), abs(low - previous_close)))
    return sum(ranges) / period


def initial_stop(candles: Sequence[Candle], side: str, config: StrategyConfig) -> float:
    if side not in {"long", "short"}:
        raise ValueError("stop side must be long or short")
    if len(candles) < max(config.atr_period + 1, config.swing_lookback):
        raise ValueError("insufficient trigger candles for a protective stop")
    price = float(candles[-1][4])
    volatility = atr(candles, config.atr_period)
    recent = candles[-config.swing_lookback :]
    if side == "long":
        technical = min(
            float(candle[3]) for candle in recent
        ) * (1 - config.stop_buffer)
        volatility_stop = price - volatility * config.atr_multiple
        return max(price * (1 - config.max_stop_distance), min(technical, volatility_stop))
    technical = max(float(candle[2]) for candle in recent) * (1 + config.stop_buffer)
    volatility_stop = price + volatility * config.atr_multiple
    return min(price * (1 + config.max_stop_distance), max(technical, volatility_stop))


def _trailing_stop(
    candles: Sequence[Candle], position: Position, config: StrategyConfig
) -> float:
    closes = _closes(candles)
    price = closes[-1]
    slow = sma(closes, config.trigger_slow)
    volatility = atr(candles, config.atr_period)
    assert position.stop_price is not None
    if position.side == "long":
        candidate = min(
            slow * (1 - config.stop_buffer),
            price - volatility * config.atr_multiple,
        )
        return max(position.stop_price, candidate)
    candidate = max(
        slow * (1 + config.stop_buffer),
        price + volatility * config.atr_multiple,
    )
    return min(position.stop_price, candidate)


def decide(
    daily: Sequence[Candle],
    four_hour: Sequence[Candle],
    trigger_candles: Sequence[Candle],
    position: Position = Position(),
    config: StrategyConfig = StrategyConfig(),
) -> Decision:
    """Return one deterministic decision using closed candles only."""
    regime = market_regime(daily, four_hour, config)
    turn = _trigger(trigger_candles, config)
    last_high = float(trigger_candles[-1][2])
    last_low = float(trigger_candles[-1][3])

    if position.side == "long":
        assert position.stop_price is not None
        if last_low <= position.stop_price:
            return Decision(Action.EXIT_LONG, regime, ("protective stop crossed",))
        if regime != Regime.BULL:
            return Decision(Action.EXIT_LONG, regime, ("daily/4h bullish alignment lost",))
        if turn == "down":
            return Decision(Action.EXIT_LONG, regime, ("small bearish cycle started",))
        return Decision(
            Action.HOLD_LONG,
            regime,
            ("large bullish cycle intact", "no small-cycle exit"),
            _trailing_stop(trigger_candles, position, config),
            1.0,
        )

    if position.side == "short":
        assert position.stop_price is not None
        if last_high >= position.stop_price:
            return Decision(Action.EXIT_SHORT, regime, ("protective stop crossed",))
        if regime != Regime.BEAR:
            return Decision(Action.EXIT_SHORT, regime, ("daily/4h bearish alignment lost",))
        if turn == "up":
            return Decision(Action.EXIT_SHORT, regime, ("small bullish cycle started",))
        return Decision(
            Action.HOLD_SHORT,
            regime,
            ("large bearish cycle intact", "no small-cycle exit"),
            _trailing_stop(trigger_candles, position, config),
            config.bear_risk_multiplier,
        )

    if regime == Regime.BULL and turn == "up":
        return Decision(
            Action.ENTER_LONG,
            regime,
            ("daily and 4h 50/200 bullish alignment", "small bullish cycle turned up"),
            initial_stop(trigger_candles, "long", config),
            1.0,
        )
    if regime == Regime.BEAR:
        if config.allow_short and turn == "down":
            return Decision(
                Action.ENTER_SHORT,
                regime,
                ("daily and 4h 50/200 bearish alignment", "reduced-size short enabled"),
                initial_stop(trigger_candles, "short", config),
                config.bear_risk_multiplier,
            )
        return Decision(
            Action.WAIT,
            regime,
            ("bearish alignment: long blocked", "short disabled or no bearish turn"),
        )
    return Decision(
        Action.WAIT,
        regime,
        ("timeframes are mixed or small cycle has no confirmed turn",),
    )


def position_size(
    equity: float,
    entry_price: float,
    stop_price: float,
    config: StrategyConfig = StrategyConfig(),
    risk_multiplier: float = 1.0,
) -> float:
    """Return base-asset size, capped by configured notional leverage."""
    values = (equity, entry_price, stop_price, risk_multiplier)
    if not all(isfinite(value) for value in values):
        raise ValueError("position inputs must be finite")
    distance = abs(entry_price - stop_price)
    if equity <= 0 or entry_price <= 0 or stop_price <= 0 or distance == 0:
        raise ValueError("equity and prices must be positive and stop must differ from entry")
    if not 0 < risk_multiplier <= 1:
        raise ValueError("risk multiplier must be between 0 and 1")
    risk_size = equity * config.risk_fraction * risk_multiplier / distance
    leverage_cap = equity * config.max_leverage / entry_price
    return min(risk_size, leverage_cap)

    """Return an entry plan only after strategy, checklist and risk approval."""
    decision = decide(
        daily=daily,
        four_hour=four_hour,
        trigger_candles=trigger_candles,
        position=position,
        config=strategy_config,
    )
    entry_actions = {Action.ENTER_LONG: "long", Action.ENTER_SHORT: "short"}
    side = entry_actions.get(decision.action)
    if side is None:
        return EntryPlanResult(decision=decision, checklist=None, trade_plan=None)

    checklist = evaluate_checklist(assessment)
    if not checklist.allowed:
        return EntryPlanResult(
            decision=decision,
            checklist=checklist,
            trade_plan=None,
            blocked_reasons=checklist.reasons,
        )

    entry_price = float(trigger_candles[-1][4])
    try:
        trade_plan = build_trade_plan(
            side=side,
            entry_price=entry_price,
            stop_price=decision.stop_price,
            equity=equity,
            leverage=leverage,
            daily_state=daily_state,
            config=risk_config,
            risk_multiplier=decision.risk_multiplier,
        )
    except RuntimeError as error:
        return EntryPlanResult(
            decision=decision,
            checklist=checklist,
            trade_plan=None,
            blocked_reasons=(str(error),),
        )
    return EntryPlanResult(
        decision=decision,
        checklist=checklist,
        trade_plan=trade_plan,
    )

"""Closed-candle evidence helpers derived from the course material.

The course did not define pivot widths or numeric thresholds. Callers must
choose and backtest those values; these helpers only encode the stated
relationships and never produce an order by themselves.
"""

from math import isfinite
from typing import Sequence


def regular_bullish_divergence(
    first_price_low: float,
    second_price_low: float,
    first_rsi_low: float,
    second_rsi_low: float,
) -> bool:
    """Price makes a lower low while RSI makes a higher low."""
    values = (first_price_low, second_price_low, first_rsi_low, second_rsi_low)
    if not all(isfinite(value) for value in values):
        raise ValueError("divergence values must be finite")
    return second_price_low < first_price_low and second_rsi_low > first_rsi_low


def regular_bearish_divergence(
    first_price_high: float,
    second_price_high: float,
    first_rsi_high: float,
    second_rsi_high: float,
) -> bool:
    """Price makes a higher high while RSI makes a lower high."""
    values = (first_price_high, second_price_high, first_rsi_high, second_rsi_high)
    if not all(isfinite(value) for value in values):
        raise ValueError("divergence values must be finite")
    return second_price_high > first_price_high and second_rsi_high < first_rsi_high


def bear_trap(low: float, close: float, support: float, recovery_buffer: float = 0.0) -> bool:
    """A completed candle pierces support and closes back above it."""
    values = (low, close, support, recovery_buffer)
    if not all(isfinite(value) for value in values) or support <= 0 or recovery_buffer < 0:
        raise ValueError("invalid bear-trap values")
    return low < support and close >= support * (1 + recovery_buffer)


def bull_trap(high: float, close: float, resistance: float, recovery_buffer: float = 0.0) -> bool:
    """A completed candle pierces resistance and closes back below it."""
    values = (high, close, resistance, recovery_buffer)
    if not all(isfinite(value) for value in values) or resistance <= 0 or recovery_buffer < 0:
        raise ValueError("invalid bull-trap values")
    return high > resistance and close <= resistance * (1 - recovery_buffer)


def relative_volume_confirmed(
    volumes: Sequence[float], lookback: int = 20, multiplier: float = 1.5
) -> bool:
    """Compare the latest completed candle with preceding completed candles."""
    if lookback < 1 or not isfinite(multiplier) or multiplier <= 0:
        raise ValueError("invalid relative-volume settings")
    if len(volumes) < lookback + 1:
        raise ValueError(f"at least {lookback + 1} volume values are required")
    recent = [float(value) for value in volumes[-(lookback + 1) :]]
    if not all(isfinite(value) and value >= 0 for value in recent):
        raise ValueError("volumes must be finite and non-negative")
    baseline = sum(recent[:-1]) / lookback
    return baseline > 0 and recent[-1] >= baseline * multiplier


def short_squeeze_context(
    price_change: float,
    open_interest_change: float,
    funding_rate: float,
    minimum_price_change: float,
    minimum_oi_change: float,
) -> bool:
    """Flag rising price/OI with negative funding as context, not an entry."""
    values = (
        price_change,
        open_interest_change,
        funding_rate,
        minimum_price_change,
        minimum_oi_change,
    )
    if not all(isfinite(value) for value in values):
        raise ValueError("OI context values must be finite")
    if minimum_price_change < 0 or minimum_oi_change < 0:
        raise ValueError("OI context thresholds cannot be negative")
    return (
        price_change >= minimum_price_change
        and open_interest_change >= minimum_oi_change
        and funding_rate < 0
    )


def time_stop_due(
    bars_held: int,
    maximum_bars: int,
    favorable_excursion_r: float,
    minimum_expected_r: float,
    indicator_still_extreme: bool,
) -> bool:
    """Exit after the configured time if the expected reaction did not occur."""
    if bars_held < 0 or maximum_bars < 1:
        raise ValueError("invalid time-stop bars")
    if not all(isfinite(value) and value >= 0 for value in (favorable_excursion_r, minimum_expected_r)):
        raise ValueError("time-stop R values must be finite and non-negative")
    return bars_held >= maximum_bars and (
        favorable_excursion_r < minimum_expected_r or indicator_still_extreme
    )

"""Inspect, export, and safely back up futures paper-trading databases."""

import argparse
import csv
from datetime import datetime, timezone
import hashlib
import json
from pathlib import Path
import sqlite3


def _require_database(path):
    source = Path(path)
    if not source.is_file():
        raise FileNotFoundError(f"Paper database not found: {source}")
    return source


def file_sha256(path):
    digest = hashlib.sha256()
    with Path(path).open("rb") as handle:
        for chunk in iter(lambda: handle.read(1024 * 1024), b""):
            digest.update(chunk)
    return digest.hexdigest()


def read_status(path):
    source = _require_database(path)
    with sqlite3.connect(source) as database:
        row = database.execute("SELECT data FROM state WHERE id=1").fetchone()
        if row is None:
            raise ValueError("Paper database has no state row")
        state = json.loads(row[0])
        event_count = database.execute("SELECT COUNT(*) FROM events").fetchone()[0]
        trade_count, net_pnl = database.execute(
            "SELECT COUNT(*), COALESCE(SUM(net_pnl),0) FROM trades"
        ).fetchone()
    return {
        "database": str(source),
        "identity": state["identity"],
        "balance": state["balance"],
        "position": state["position"],
        "last_candle": state["candle"],
        "daily": state["daily"],
        "events": event_count,
        "closed_trades": trade_count,
        "closed_net_pnl": net_pnl,
    }


def backup_database(source_path, destination_path):
    source = _require_database(source_path)
    destination = Path(destination_path)
    if destination.exists():
        raise FileExistsError(f"Backup destination already exists: {destination}")
    destination.parent.mkdir(parents=True, exist_ok=True)
    with sqlite3.connect(source) as source_database:
        with sqlite3.connect(destination) as destination_database:
            source_database.backup(destination_database)
    return {
        "source": str(source),
        "backup": str(destination),
        "sha256": file_sha256(destination),
        "bytes": destination.stat().st_size,
    }


def _write_query_csv(database, query, destination):
    cursor = database.execute(query)
    with Path(destination).open("x", newline="", encoding="utf-8") as handle:
        writer = csv.writer(handle)
        writer.writerow(column[0] for column in cursor.description)
        writer.writerows(cursor)


def export_database(source_path, output_directory):
    source = _require_database(source_path)
    output = Path(output_directory)
    output.mkdir(parents=True, exist_ok=False)
    snapshot = output / "snapshot.sqlite3"
    backup_database(source, snapshot)

    with sqlite3.connect(snapshot) as database:
        state_row = database.execute("SELECT data FROM state WHERE id=1").fetchone()
        if state_row is None:
            raise ValueError("Paper database has no state row")
        (output / "state.json").write_text(
            json.dumps(json.loads(state_row[0]), ensure_ascii=False, indent=2),
            encoding="utf-8",
        )
        _write_query_csv(
            database,
            "SELECT candle,event,payload,created_at FROM events ORDER BY candle",
            output / "events.csv",
        )
        _write_query_csv(
            database,
            """
            SELECT opened_at,closed_at,side,entry_price,exit_price,quantity,
                   gross_pnl,fees,net_pnl,reason
            FROM trades ORDER BY opened_at
            """,
            output / "trades.csv",
        )

    files = [snapshot, output / "state.json", output / "events.csv", output / "trades.csv"]
    manifest = {
        "created_at": datetime.now(timezone.utc).isoformat(),
        "source": str(source),
        "files": {
            item.name: {"sha256": file_sha256(item), "bytes": item.stat().st_size}
            for item in files
        },
    }
    (output / "manifest.json").write_text(
        json.dumps(manifest, ensure_ascii=False, indent=2),
        encoding="utf-8",
    )
    return manifest


def backup_all(data_directory, output_directory):
    data = Path(data_directory)
    sources = sorted(data.glob("*.sqlite3"))
    if not sources:
        raise FileNotFoundError(f"No paper databases found in {data}")
    stamp = datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%SZ")
    target = Path(output_directory) / stamp
    target.mkdir(parents=True, exist_ok=False)
    results = [
        backup_database(source, target / source.name)
        for source in sources
    ]
    manifest = {
        "created_at": datetime.now(timezone.utc).isoformat(),
        "backups": results,
    }
    (target / "manifest.json").write_text(
        json.dumps(manifest, ensure_ascii=False, indent=2),
        encoding="utf-8",
    )
    return target, manifest


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    commands = parser.add_subparsers(dest="command", required=True)

    status_parser = commands.add_parser("status")
    status_parser.add_argument("--state", required=True)

    backup_parser = commands.add_parser("backup")
    backup_parser.add_argument("--state", required=True)
    backup_parser.add_argument("--output", required=True)

    export_parser = commands.add_parser("export")
    export_parser.add_argument("--state", required=True)
    export_parser.add_argument("--output-dir", required=True)

    all_parser = commands.add_parser("backup-all")
    all_parser.add_argument("--data-dir", required=True)
    all_parser.add_argument("--output-dir", required=True)

    args = parser.parse_args()
    if args.command == "status":
        result = read_status(args.state)
    elif args.command == "backup":
        result = backup_database(args.state, args.output)
    elif args.command == "export":
        result = export_database(args.state, args.output_dir)
    else:
        target, manifest = backup_all(args.data_dir, args.output_dir)
        result = {"directory": str(target), **manifest}
    print(json.dumps(result, ensure_ascii=False, indent=2))


if __name__ == "__main__":
    main()

"""Pre-trade checklist extracted from the course workflow.

This module does not score indicators. Every item must be reviewed, while the
location, timeframe, volume and price-structure gates must also pass.
"""

from dataclasses import dataclass


@dataclass(frozen=True)
class ChecklistAssessment:
    signal_reviewed: bool
    location_reviewed: bool
    location_valid: bool
    timeframe_reviewed: bool
    timeframe_aligned: bool
    volume_reviewed: bool
    volume_confirmed: bool
    repeated_signal_risk_reviewed: bool
    structure_reviewed: bool
    structure_confirmed: bool
    oi_reviewed: bool
    vetoes: tuple[str, ...] = ()


@dataclass(frozen=True)
class ChecklistResult:
    allowed: bool
    reasons: tuple[str, ...]


def evaluate_checklist(assessment: ChecklistAssessment) -> ChecklistResult:
    reviews = {
        "divergence/trap classification not reviewed": assessment.signal_reviewed,
        "volume-zone location not reviewed": assessment.location_reviewed,
        "signal timeframe and holding plan not reviewed": assessment.timeframe_reviewed,
        "volume not reviewed": assessment.volume_reviewed,
        "repeated-divergence risk not reviewed": assessment.repeated_signal_risk_reviewed,
        "price structure not reviewed": assessment.structure_reviewed,
        "open interest not reviewed": assessment.oi_reviewed,
    }
    gates = {
        "setup is outside an approved volume zone": assessment.location_valid,
        "signal timeframe conflicts with holding plan": assessment.timeframe_aligned,
        "volume confirmation is absent": assessment.volume_confirmed,
        "price structure is not confirmed": assessment.structure_confirmed,
    }
    reasons = [message for message, passed in reviews.items() if not passed]
    reasons.extend(message for message, passed in gates.items() if not passed)
    reasons.extend(f"veto: {message}" for message in assessment.vetoes)
    return ChecklistResult(not reasons, tuple(reasons) or ("all seven checks completed",))

def _database_connection(path):
    connection = sqlite3.connect(
        f"file:{Path(path).resolve()}?mode=ro",
        uri=True,
        timeout=5,
    )
    connection.row_factory = sqlite3.Row
    connection.execute("PRAGMA query_only=ON")
    connection.execute("PRAGMA busy_timeout=5000")
    return connection


def _symbol_from_identity(identity, fallback):
    if isinstance(identity, list) and identity and isinstance(identity[0], str):
        return identity[0].split("/")[0]
    return fallback.upper()


def read_dashboard_database(path, recent_limit=RECENT_LIMIT):
    """Read one database without acquiring the trader's exclusive lock."""
    if not 1 <= recent_limit <= 100:
        raise ValueError("recent_limit must be between 1 and 100")

    source = Path(path)
    with _database_connection(source) as database:
        row = database.execute("SELECT data FROM state WHERE id=1").fetchone()
        if row is None:
            raise ValueError("Database has no state row")
        state = json.loads(row["data"])

        events = []
        for item in database.execute(
            """
            SELECT candle,event,payload,created_at
            FROM events ORDER BY candle DESC LIMIT ?
            """,
            (recent_limit,),
        ):
            try:
                payload = json.loads(item["payload"])
            except json.JSONDecodeError:
                payload = {}
            events.append(
                {
                    "candle": item["candle"],
                    "event": item["event"],
                    "payload": payload,
                    "created_at": item["created_at"],
                }
            )

        trades = [
            dict(item)
            for item in database.execute(
                """
                SELECT opened_at,closed_at,side,entry_price,exit_price,quantity,
                       gross_pnl,fees,net_pnl,reason
                FROM trades ORDER BY closed_at DESC LIMIT ?
                """,
                (recent_limit,),
            )
        ]
        totals = database.execute(
            """
            SELECT COUNT(*) AS count,
                   COALESCE(SUM(net_pnl),0) AS net_pnl,
                   COALESCE(SUM(fees),0) AS fees
            FROM trades
            """
        ).fetchone()

    symbol = _symbol_from_identity(state.get("identity"), source.stem)
    return {
        "id": source.stem,
        "symbol": symbol,
        "balance": state.get("balance", 0),
        "position": state.get("position"),
        "last_candle": state.get("candle", 0),
        "daily": state.get("daily"),
        "closed_trades": totals["count"],
        "closed_net_pnl": totals["net_pnl"],
        "total_fees": totals["fees"],
        "recent_events": events,
        "recent_trades": trades,
    }


def discover_databases(data_directory=DATA_DIRECTORY):
    directory = Path(data_directory)
    if not directory.is_dir():
        return []
    return sorted(directory.glob("*.sqlite3"))


def build_dashboard(data_directory=DATA_DIRECTORY, recent_limit=RECENT_LIMIT):
    accounts = []
    errors = []
    for path in discover_databases(data_directory):
        try:
            accounts.append(read_dashboard_database(path, recent_limit))
        except (OSError, sqlite3.Error, ValueError, json.JSONDecodeError) as error:
            errors.append({"database": path.name, "error": str(error)})
    return {
        "generated_at": datetime.now(timezone.utc).isoformat(),
        "accounts": accounts,
        "errors": errors,
    }

from dataclasses import replace

from trade_checklist import ChecklistAssessment, evaluate_checklist


def complete_assessment():
    return ChecklistAssessment(
        signal_reviewed=True,
        location_reviewed=True,
        location_valid=True,
        timeframe_reviewed=True,
        timeframe_aligned=True,
        volume_reviewed=True,
        volume_confirmed=True,
        repeated_signal_risk_reviewed=True,
        structure_reviewed=True,
        structure_confirmed=True,
        oi_reviewed=True,
    )


def test_all_seven_reviews_and_required_gates_allow_entry():
    result = evaluate_checklist(complete_assessment())
    assert result.allowed
    assert result.reasons == ("all seven checks completed",)


def test_missing_review_and_failed_gate_block_without_scoring():
    assessment = replace(
        complete_assessment(),
        oi_reviewed=False,
        volume_confirmed=False,
    )
    result = evaluate_checklist(assessment)
    assert not result.allowed
    assert "open interest not reviewed" in result.reasons
    assert "volume confirmation is absent" in result.reasons


def test_market_veto_always_blocks_entry():
    result = evaluate_checklist(
        replace(complete_assessment(), vetoes=("top-holder concentration risk",))
    )
    assert not result.allowed
    assert result.reasons == ("veto: top-holder concentration risk",)

import json

from futures_paper import PaperState
from web_app import build_dashboard, read_dashboard_database


def make_database(path, symbol="BTC/USDT:USDT"):
    state = PaperState(path, [symbol], 1_000)
    state.record_event(1_700_000_000_000, "wait", {"price": 35_000})
    state.record_trade(
        {
            "opened_at": 1_699_999_000_000,
            "closed_at": 1_700_000_000_000,
            "side": "long",
            "entry_price": 34_000,
            "exit_price": 35_000,
            "quantity": 0.01,
            "gross_pnl": 10,
            "fees": 0.5,
            "net_pnl": 9.5,
            "reason": "target",
        }
    )
    state.data["balance"] = 1_009.5
    state.data["candle"] = 1_700_000_000_000
    state.save()
    return state


def test_dashboard_reads_live_database_without_mutating_it(tmp_path):
    path = tmp_path / "btc-v1.sqlite3"
    state = make_database(path)
    before = path.read_bytes()

    result = read_dashboard_database(path)

    assert result["symbol"] == "BTC"
    assert result["closed_net_pnl"] == 9.5
    assert result["total_fees"] == 0.5
    assert result["recent_events"][0]["payload"]["price"] == 35_000
    assert result["recent_trades"][0]["reason"] == "target"
    assert path.read_bytes() == before
    state.db.close()
    state.lock.close()


def test_dashboard_isolates_a_broken_database(tmp_path):
    state = make_database(tmp_path / "btc-v1.sqlite3")
    (tmp_path / "broken.sqlite3").write_text("not sqlite", encoding="utf-8")

    result = build_dashboard(tmp_path)

    assert [account["symbol"] for account in result["accounts"]] == ["BTC"]
    assert result["errors"][0]["database"] == "broken.sqlite3"
    json.dumps(result)
    state.db.close()
    state.lock.close()
